デモ｜物件情報の巡回監視Bot

右側の「今日の巡回結果」の価格やチェックを自由に変えて、「巡回を実行」を押してください。差分を検知し、LINEに送る通知文を組み立てます。

このデモについて：差分検知の部分は、実際に毎朝8:00に動いている crawl.py の detect_events() を JavaScript にそのまま移植したものです。物件データはダミーで、本番では不動産サイト2つ（約400件）を自動で取得します。通知の閾値は本番と同じ「100万円以下」です。
